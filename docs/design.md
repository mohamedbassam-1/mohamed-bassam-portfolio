# V5 — open compositions and real products

## Visual direction

ICE uses cold pearl, misty blue light, restrained violet, and deep navy typography. NIGHT uses blue-black, navy, controlled cyan, and small emerald accents. Inter carries the hierarchy; IBM Plex Mono is limited to compact metadata. A low-opacity static grain gives gradients texture without a rendering loop. The thinner floating navigation adapts to each project environment and becomes slightly quieter while scrolling down.

Most sections use typography, photography, screenshots, and open space rather than cards. Buttons have moderate corners and restrained movement. The native browser cursor is used throughout; the custom cursor's markup, styles, attributes, and JavaScript remain removed.

## Three signature moments

1. **Hero:** a full-height statement, three actions, and one open SVG signal composition. Four labels connect the artwork to agentic AI, vision, forecasting, and NLP. Pointer response is subtle; there are no hero tabs, project windows, or dashboard controls. Mobile reduces the number of paths and disables pointer depth.
2. **Dark Agent:** a deep navy/emerald product chapter with large real screenshots, a six-screen scroll journey, and a spacious nine-stage architecture. Selecting a stage reveals one concise description. Mobile puts screenshots in normal flow and makes the architecture vertical. The 13-image archive remains available.
3. **Project reel:** six projects with roughly two-thirds of the desktop composition devoted to artwork, short adjacent information, and gentle visual transitions. A plain text index, previous/next controls, keyboard selection, and touch swiping support browsing.

Everything else is calmer. The capability map reveals technologies without animated chrome. The real portrait is prominent, lightly desaturated, and feathered into the page. Personal facts and one human line accompany short copy. Experience uses large years, a thin timeline, and optional details.

## Implementation and usability

The stylesheet and major compositions are replaced rather than covered with another override layer. The existing static build, deployment configuration, optimized assets, fonts, CV, and structured metadata remain intact. No runtime framework, WebGL, canvas loop, external font service, or animation dependency is added.

Native scrolling is preserved. Keyboard controls provide equivalent access to selections, and hover is supplementary. Reduced motion removes animated reveals, spatial response, smooth scrolling, and decorative loops. Image dialogs contain keyboard focus, close with Escape, and restore the trigger. Without JavaScript, project panels, architecture explanations, original-image links, and mobile navigation remain available. Decorative animation pauses outside the viewport.
