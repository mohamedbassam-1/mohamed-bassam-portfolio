# V4 — spatial AI engineering portfolio

## Visual system

Pearl and frost surfaces, navy typography, atmospheric cyan light, and controlled violet accents define ICE. NIGHT uses blue-black and soft navy, with brighter cyan typography. Inter is the primary typeface; IBM Plex Mono is confined to small counts and technical metadata. The fixed side index and repeated ruled compositions were removed. A translucent floating dock adapts to the darker project environments.

## Seven-part design plan

1. **Visual system:** layered light, selective translucency, soft shadows, open layouts, and a consistent sans-serif hierarchy.
2. **Hero:** an abstract intelligence architecture made from CSS perspective planes, restrained SVG connections, five real project previews, and subtle pointer response. Dark Agent is the initial, dominant interface.
3. **Signature interactions:** the hero sculpture, a six-branch capability ecosystem, and an inspectable nine-stage architecture. The transforming gallery adds a fourth custom interaction.
4. **Dark Agent:** a gradual navy/emerald transition, a large six-screen product walkthrough, an illuminated execution route, agent roles, hybrid retrieval, and a replayable illustrated validation sequence. Deeper decisions remain in disclosures.
5. **SmartInvest:** a separate deep-blue environment, a decorative financial trace, large real screens, and a six-stage data → models → ensemble → confidence → risk → paper-trade pipeline. Decorative charts never imply investment performance.
6. **Project gallery:** large interface imagery, changing descriptions and stacks, source/context links, a compact floating selector on desktop, and real touch swiping on mobile.
7. **Mobile:** simplified sculpture, compact navigation overlay, vertical architecture, normal-flow product screens, large image previews, and lighter animation.

## Implementation and usability

V4 replaces the former DOM compositions, stylesheet, and index/storytelling JavaScript. It is not a CSS override layer. Existing metadata, factual evidence, originals, optimized screenshots, fonts, CV, and deployment configuration remain intact.

Native scrolling is retained. Keyboard interaction is equivalent to pointer interaction, and hover is supplementary. Reduced motion removes animated reveals and spatial response. Image dialogs contain keyboard focus, close with Escape, and restore the trigger. Without JavaScript, project panels and architecture explanations remain readable and original-image links still work. Decorative loops pause outside the viewport. No WebGL, canvas loop, animation framework, or frontend runtime is shipped.
