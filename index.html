04Design decisions & operations+

The thinking behind the build

Every constraint
has a reason.

Why selective agents?+

Reduce unnecessary model calls and token consumption by running only the agents a mission needs.

Why success-only credits?+

Users should not pay for failed execution. Deduction happens only after successful response generation.

Why database transactions?+

Concurrent requests must not overspend the same credit balance. Settlement is a transactional operation.

Why query-level tenant scoping?+

Isolation cannot depend on frontend behavior. Retrieval and mission-journal queries are scoped to the authenticated Clerk user.

Why tool allowlists?+

Each agent receives only its permitted tool surface. Least privilege makes the boundary explicit.

Why separate background workers?+

Durable workloads and scheduled Sentinels are separated from interactive requests. Azure Service Bus supports the infrastructure preparation.

Why backend entitlements?+

Subscription fulfillment, model access, rate limits, and idempotent webhooks must be verified by the server.

Security, context & operations +

Black Vault & Ghost Mode

Black Vault supports local evidence sanitization and cryptographic manifests before documents enter the workflow. Ghost Mode provides an ephemeral path designed to avoid retaining mission content in persistent conversation history.

Model routing & secure MCP

Provider-aware routing selects OpenAI and Anthropic models according to task complexity, entitlement, latency, and cost requirements. Read-only GitHub and Notion connectors retrieve credentials through a Key Vault boundary rather than raw tokens in application tables.

Product infrastructure

Next.js 16 and TypeScript connect to Python, FastAPI, LangGraph, PostgreSQL, and WebSockets. Docker, Azure Service Bus, and Azure Key Vault support Azure deployment preparation.
